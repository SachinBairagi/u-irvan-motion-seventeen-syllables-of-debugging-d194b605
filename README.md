Seventeen Syllables of Debugging: one haiku about debugging in the 5-7-5 shape, written by a small deterministic program that checks the form and writes the three lines to entry.txt. A cursor blinking at three in the morning, the line where the build broke, and the one semicolon behind it all.

## The haiku

```
Three in the morning
cursor blinks where the build broke
one semicolon
```

## Run it

```sh
python3 main.py
```

The program validates the haiku (three lines, 5-7-5 syllables, under 200 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that is unset. It needs no network and no input, and every run writes the same bytes.
